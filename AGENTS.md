# Public documentation

POSIM is public product source. Keep dated experiment reports, comparison results,
V&V captures, investigation scripts and development history in a separate
development archive. Retain product implementation, reusable
automated tests and current user/contributor documentation here. Describe how a
feature works; preserve the investigation and repair history in the private record.

For user-facing README files, website guides and generated pages, follow
[website/AGENTS.md](website/AGENTS.md). Keep engineering history and validation
records outside user guides. Update Korean and English together, regenerate
the website, and run its documentation checks.

POSIM is the simulation engine. WWW-POSIM is the application package that uses it.
