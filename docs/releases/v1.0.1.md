# POSIM 1.0.1

Status: release candidate. The final release has not been published.

POSIM 1.0.1 is a patch release for the ROS 2 Lyrical / Gazebo Jetty stack.
It fixes missing runtime paths in fresh RDP desktops, corrects material and
buffer handling for dynamic geometry, and repairs native installation steps.

## Corrections

- Fresh Apple Silicon RDP sessions receive the Wave Sim model and library paths
  and the existing Terra resource overlay. Starting a tutorial no longer depends
  on manually exporting these paths in that desktop session.
- Dynamic geometry preserves its active PBS or legacy material across buffer
  updates. The corrected gz-rendering and Wave Sim paths release persistent
  vertex mappings before destroying their buffers.
- The Ubuntu/WSL installer and AMD64/ARM64 Docker recipes build these corrections
  from pinned sources. The renderer uses a separate prefix and leaves files
  owned by ROS packages unchanged. Sourcing ROS underlays preserves the
  corrected renderer's priority, including in an existing RDP environment.
- Native installation retains APT package indexes so the following workspace
  dependency installation can resolve its packages.
- Standalone renderer tests no longer appear as ROS packages during colcon
  discovery. Their native build resolves Wave Sim library dependencies at link time.

## Build and distribution

- AMD64 Docker builds now run on GitHub-hosted Ubuntu 26.04. All POSIM workflows
  use GitHub-hosted runners, with native AMD64 and ARM64 image builds and pinned
  Buildx and BuildKit versions.
- Both architecture images must pass their installed-image tests before
  publication. Versioned Docker publication verifies each architecture's source
  revision and adds the release tag to the existing commit image digest.
- The project README includes a graphical overview in all eight languages.

## Regression coverage

- Image acceptance checks include material name collisions, geometry resizing,
  material transitions, loaded-library selection and upstream lidar/GPU-ray
  and renderer load/unload tests.

## Installation

Use the [installation guide](../../website/content/en/install.md) and the
[first simulation guide](../../website/content/en/quickstart.md).
The planned Docker tag is `ioeslab/posim:1.0.1`; this candidate does not announce
its availability. Use the exact commit image identified by the release candidate
PR for testing once both architecture builds and publication have passed.
The final release will identify the verified version tag and image digest.

Use a fresh container to adopt the updated runtime dependencies; existing
containers retain their previous image. For a native installation, rerun the
documented dependency installation and rebuild the POSIM workspace from the
selected source revision so the corrected rendering libraries are installed.

The supported desktop paths remain Ubuntu 26.04, Windows with WSL 2, and
Apple Silicon with Linux ARM64 Docker and RDP. Native macOS rendering is not
part of this release's supported installation.

## Limits

The corrections do not claim to eliminate every Ogre material, UV/tangent or
shutdown diagnostic. They do not change vehicle physics, arming checks, sensor
accuracy or QGroundControl video settings. Simulation tests do not establish
real-vehicle safety or a guaranteed video rate.

See [1.0.0](v1.0.0.md) for the feature set and
[license and attribution](../../README.md#license-and-attribution) for dependency
licenses. Retained Wave Sim source and GPL notices remain part of the image.
