# POSIM 1.0.0

POSIM is an open-source maritime robotics simulation library for Gazebo Sim
and ROS 2. The first stable release brings together ocean environments,
underwater and surface robots, simulated sensors and control interfaces.

## Highlights

- Start with REXROV, BlueROV2, Slocum glider or WAM-V. Run the supplied worlds,
  or combine the models and systems in your own SDF.
- Simulate surface waves, ocean currents and underwater optical effects.
  Observe camera, pressure, DVL, USBL, GNSS and multibeam sonar data.
- Use ROS 2 topics, services and Python for control and recording. ArduSub
  and ArduRover SITL 4.7.2 support the supplied MAVROS workflows. BlueROV2
  can stream camera video to QGroundControl.
- Select CPU, WGPU or CUDA for multibeam sonar. The physical receive model
  uses CPU or WGPU. Gazebo rendering is required for each backend.

## Get started

The supported stack is ROS 2 Lyrical and Gazebo Jetty on Ubuntu 26.04. Use
native Ubuntu, Linux Docker, Windows WSL 2, or Docker and RDP on Apple
Silicon. Follow [Choose an environment](https://ioes-lab.github.io/POSIM/requirements.html)
and [First simulation](https://ioes-lab.github.io/POSIM/quickstart.html).

Use the `v1.0.0` Git tag or the `ioeslab/posim:1.0.0` Docker image to
reproduce this release. Record the image digest or source commit alongside
your world, vehicle and sensor settings.

For an existing source installation, rerun dependency setup and rebuild the
workspace from a clean shell. ArduPilot 4.7.2 changes some parameter names.
Start with the supplied 1.0.0 profiles before migrating custom parameters.

## Known limits

- Apple Silicon Docker uses Linux rendering. Native Metal requires a
  separately configured ROS and Gazebo SDK. On the tested Gazebo 10.5
  macOS SDK, sonar-only worlds can fail during renderer startup. Include
  a built-in camera in that configuration.
- Graphics performance depends on the renderer and sensor workload.
  The sonar and surface vehicle models require calibration for quantitative
  comparisons with physical equipment.
