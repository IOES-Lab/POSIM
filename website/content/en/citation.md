# Citation and licenses

IOES-Lab maintains POSIM. Preserve authorship and component notices when using or distributing it.

## Cite the simulation foundation

The DAVE project paper describes the aquatic simulation environment:

Zhang and collaborators, *DAVE Aquatic Virtual Environment: Toward a General Underwater Robotics Simulator*, IEEE/OES Autonomous Underwater Vehicles Symposium, 2022. [DOI: 10.1109/AUV53081.2022.9965808](https://doi.org/10.1109/AUV53081.2022.9965808).

For the multibeam sonar model:

Choi and collaborators, *Physics-Based Modelling and Simulation of Multibeam Echosounder Perception for Autonomous Underwater Manipulation*, Frontiers in Robotics and AI, 2021. [DOI: 10.3389/frobt.2021.706646](https://doi.org/10.3389/frobt.2021.706646).

Include the POSIM source revision, robot/world configuration and relevant dependencies in an experiment's reproducibility record. Use the original publication's bibliographic record for complete author/title metadata.
