# 创建世界

先创建一个小型世界，在已知深度放置压力传感器。加入地形和移动机器人之前，先观察环境设置如何影响测量结果。

## 准备工作环境

使用 Ubuntu 原生安装、WSL 或 Docker 中[准备好的 Linux 终端](terminals.md)。macOS 用户使用 RDP 桌面内的终端。编辑和编译都在该环境内完成；`POSIM_WS` 表示其工作空间路径。

## 改变深度

1. 在终端 A 按 Ctrl+C 停止仿真。
2. 将观测点位姿从 `0 0 -2 0 0 0` 改成 `0 0 -4 0 0 0`。
3. 再次校验并启动。
4. 再次运行两个话题查询命令，预期约为 **140,551 Pa** 和 **4 m**。

保持压力系数不变。压力应增加 **19,612.76 Pa**。将修改前后的文件与观测结果一起保存。

## 找到各项设置

| SDF 路径 | 单位 | 用途 |
|---|---|---|
| `world/physics/max_step_size` | s | 最大积分步长：`0.001` |
| `world/physics/real_time_factor` | — | 仿真时间与实际时间的目标比值：`1.0` |
| `world/gravity` | m/s² | 重力向量 |
| `world/scene`, `world/light` | RGBA / 方向 | 背景和照明 |
| `model/pose` | m, rad | 位置和姿态 |
| `model/static` | 布尔值 | 固定观测点与海底 |
| `model/plugin` | 依插件而定 | [压力参数](pressure.md) |

实际速度取决于运行负载。传感器定义与世界系统的作用范围不同。[添加传感器](custom-sensors.md)将进一步为此文件加入 IMU 和 ROS 桥接。
