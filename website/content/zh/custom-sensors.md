# 添加与配置传感器

传感器需要模型定义、负责更新的系统，以及通向接收程序的数据链路。每次添加一个传感器，确认测量正常后再继续。

## 工作环境

使用 Ubuntu 原生安装、WSL 或 Docker 中[准备好的 Linux 终端](terminals.md)。macOS 用户在 RDP 桌面内操作。编辑和编译都在该环境中完成；`POSIM_WS` 表示其工作空间。

## 选择集成位置

| 测量 | 模型中的位置 | 世界系统 / ROS 连接 |
|---|---|---|
| IMU | `link/sensor type="imu"` | IMU 系统；将 `gz.msgs.IMU` 桥接为 ROS `Imu` |
| [水下相机](camera.md) | RGBD 传感器与图像效果插件 | 带渲染器的 Sensors 系统及相机话题 |
| [DVL](dvl.md) | DVL 传感器与波束配置 | DVL 系统及随附的声学消息桥接 |
| [压力](pressure.md) | `model` 下的直接子插件 | 直接发布 ROS 压力与深度消息 |
| [海洋 GNSS](gnss.md) | 机器人模型上的接收机插件 | 接收机配置的 ROS 输出 |
| [USBL](usbl.md) | 收发机与应答器插件 | 匹配的声学标识及 ROS 接口 |
| [多波束声纳](sonar.md) | 连杆下的自定义传感器 | Sensors 渲染器、世界多波束系统及 CPU/WGPU/CUDA |

参考各页的 SDF 和参数表，并遵守插件位置要求：世界系统放在世界中，模型插件放在其作用的模型中。

## 改变更新频率

将 `update_rate` 从 `20` 改为 `5`，重新启动世界和桥接。相邻时间戳间隔应从约 **0.05 秒变为 0.2 秒**仿真时间。按实际时间计算的接收频率还取决于实时因子和传输过程。

相机应一起检查分辨率、视场角及近远裁剪距离。扫描传感器应检查波束几何和量程。移动传感器前，先确认所属连杆的坐标系和朝向。

## 核对集成结果

- 模型：有效的安装位姿、参数和唯一话题。
- 世界：所需系统，以及图像传感器使用的渲染器。
- ROS：桥接方向、消息类型、坐标系和 QoS。
- 数据：持续更新的时间戳，以及对受控场景变化的响应。

用[高度图地形](heightmaps.md)检查海底位置。声纳对比实验请结合[配置与性能](sonar-tuning.md)和[参数参考](sonar.md)。
