# 海上 GNSS

`posim_gz_gnss` はモデルのアンテナリンクに衛星測位受信機を再現します。ワールド位置を地理座標に変換し、設定可能なガウス誤差を加え、位置・速度・取得時刻・状態を 1 つのメッセージで出力します。水没による受信喪失、明示的な遮蔽、再捕捉、遅延を扱います。

## 受信機をビルドして取り付ける

リンクとトピックをロボットに合わせます。モデルの準備と起動は[ロボットを作る](custom-robots.md)を参照してください。

[プロファイル](https://github.com/IOES-Lab/POSIM/blob/main/gazebo/posim_gz_gnss/config/profiles.json)の取り付け位置は `base_link` 基準で、WAM-V は z = 1.8 m、BlueROV2 は 0.3 m、REXROV は 0.8 m です。WAM-V と BlueROV2 の 3 種類のプロファイルは受信機を有効にし、REXROV は既定で無効にします。プロファイルは取り付け設定のデータなので、リンクとプラグインはモデルへ組み込む必要があります。WAM-V には[外部の Wave Sim モデル](surface.md)も必要です。

BlueROV2、BlueROV2 Heavy、ソナー搭載型には受信機と `marine_gnss_input` アダプターが含まれます。ArduSub 使用時は SITL の合成 GPS の代わりに MAVROS `GPSINPUT` を送信します。速度を ENU から NED に変換し、インストール済みの GeographicLib データで WGS 84 楕円体高を EGM96 平均海面高に変換します。水没、遮蔽、無効値、未来の時刻、1 s を超えた古い測定は測位不能として送信します。有効な測位でも衛星数は不明（`255`）で、衛星配置と DOP は計算しません。サンプルの受信機は表示上の波とは独立に平均水面 z = 0 を使います。

## パラメーター

| SDF パラメーター | 単位・意味 | 既定値 |
|---|---|---|
| `update_rate` | シミュレーション 1 秒あたりの計測数。0 より大きく 100 Hz 以下 | 5 |
| `latency` | 計測の伝達遅延、シミュレーション秒。0～10 s | 0.2 |
| `reacquire_seconds` | 水面上で連続して捕捉に必要な時間、s | 3 |
| `dry_margin` | 捕捉に必要な水面からの余裕高さ、m | 0.05 |
| `horizontal_stddev` | 水平位置の標準偏差、m | 0.7 |
| `vertical_stddev` | 鉛直位置の標準偏差、m | 1.2 |
| `velocity_stddev` | 速度の標準偏差、m/s | 0.1 |
| `water_level` | 波トピックを使わない場合の平均水面 z、m | 0 |
| `seed` | 受信機の乱数シード | 42 |
| `enabled` | 受信機を有効化 | true |
| `link_name` | モデル内のアンテナリンク | `gnss_link` |
| `topic` | Gazebo 計測トピック | `/model/<model-name>/gnss` |
| `wave_topic` | 任意の水面高さトピック | 空 |

数値設定は有限である必要があります。遅延、捕捉時間、余裕高さ、標準偏差は非負です。

## 局所的な水面高さ

`wave_topic` が空なら平均水面を使います。指定した場合は新しい局所水面データが必要で、欠落や無効なデータは `surface unavailable` になります。

`gz.msgs.Double_V` は、スキーマ `1`、格子サイズ、周期的な X/Y 寸法、風速・風向角、波形勾配、シミュレーション時刻、行順の高さ値をこの順で持ちます。

- 格子サイズは 2～256 の整数で、高さ値の個数はその 2 乗です。
- X/Y 寸法は有限かつ正です。
- 時刻は有限で、現在より **0.6 シミュレーション秒**以内の過去である必要があります。未来の値は使えません。

対応する配信元は別途設定します。風のメタデータは受信状態を制御しません。

## 計測と遮蔽を確認する

設定したモデルを起動し、準備済みのターミナル B で読み取ります。

{{CODE:gnss:2}}

メッセージは 15 個の double 値です。インデックスは 0 始まりです。遅れて届いた測位結果も、取得時刻を保持して扱ってください。

| インデックス | 項目・単位 |
|---|---|
| 0～3 | スキーマ `1`、リセット識別子 epoch、取得時刻（シミュレーション秒）、状態 |
| 4～6 | 緯度（度）、経度（度）、高度（m） |
| 7～9 | 東・北・上向き速度、m/s |
| 10～12 | 水平・鉛直位置分散（m²）、速度分散（(m/s)²） |
| 13～14 | アンテナのワールド z と局所水面高さ、m |

状態は `0 disabled`（無効）、`1 submerged`（水没）、`2 acquiring`（捕捉中）、`3 fix`（測位有効）、`4 blocked`（遮蔽）、`5 surface unavailable`（水面情報なし）です。

無効な計測の座標と速度は `NaN` です。水面接触や遮蔽で未配信の測位結果を破棄します。再捕捉には余裕高さを超えた状態の連続維持が必要です。リセットはタイマーと遅延中の計測を消去し、epoch を進めます。

アンテナを遮蔽する入力です。解除する場合は `false` にします。

## 解釈と確認

静止した水面上のアンテナ、水没、遮蔽、回復を比較します。捕捉時間、遅延、リセット後の epoch、取得時刻の増加を確認してください。受信側は古い値や未来の値を除外し、無効状態を処理します。

付属の BlueROV2 アダプターは ArduSub に接続します。他の ROS `NavSatFix` 利用先や独自のオートパイロットにはアダプターが必要です。

これはアンテナ姿勢に基づくモデルです。衛星配置、RF 伝搬、物理的なマルチパス、音響測位は計算しません。精度設定はシミュレーションの入力値で、メーカーの精度保証ではありません。[実装](https://github.com/IOES-Lab/POSIM/blob/main/gazebo/posim_gz_gnss/Gnss.cc)と[パッケージガイド](https://github.com/IOES-Lab/POSIM/tree/main/gazebo/posim_gz_gnss)も参照してください。
