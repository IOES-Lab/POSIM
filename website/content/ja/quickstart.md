# 最初のシミュレーション

海のワールドで REXROV を 1 台起動し、計測データを受信してから終了します。最初は指定のロボットとワールドをそのまま使ってください。

## ターミナルを準備する

[インストール](requirements.md)を完了し、[ROS と POSIM を読み込んだターミナルを 2 つ](terminals.md)開きます。A はシミュレーターを実行し、B はデータを確認します。Docker では、設定済みの Linux デスクトップ、WSLg、RDP に Gazebo が表示されます。

## 4. 終了する

**A で Ctrl+C** を押し、プロセスの終了を待ちます。トピックの表示を止めてもシミュレーターは動き続けます。別の例を試す前に、現在のシミュレーションを停止してください。
