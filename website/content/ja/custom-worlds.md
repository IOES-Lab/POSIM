# ワールドを作る

小さなワールドを作り、深度が分かっている位置に圧力センサーを置きます。地形や動くロボットを追加する前に、設定変更と計測結果の関係を確認しましょう。

## 作業環境を準備する

Ubuntu ネイティブ、WSL、Docker の[準備済み Linux ターミナル](terminals.md)を使います。macOS では RDP デスクトップ内のターミナルを使ってください。編集とビルドもその環境内で行います。`POSIM_WS` はそのワークスペースのパスです。

## 完全なワールドを保存する

以下を `calm_water.sdf` として保存します。基本形状とインストール済みプラグインを使うため、メッシュのダウンロードは不要です。

{{CODE:custom-worlds:0}}

このワールドには次の要素があります。

- **物理設定：** 最大時間刻み 0.001 秒、シミュレーション時間と実時間の目標比 1、下向きの重力。
- **照明とシーン：** 平行光源の太陽、環境光、背景色。
- **海底：** z = −20 m に固定した箱。表示形状と衝突形状は一致しています。
- **圧力観測点：** z = −2 m の固定マーカー。モデル直下の[圧力プラグイン](pressure.md)が圧力と推定深度を出力します。

圧力の基準面はワールドの z = 0 です。まずこの例を確認し、その後に波、浮力、ロボットの動きを加えます。

## 深度を変える

1. ターミナル A を Ctrl+C で停止します。
2. 観測点の姿勢を `0 0 -2 0 0 0` から `0 0 -4 0 0 0` に変更します。
3. 再検証して起動します。
4. 2 つのトピックを再度読みます。期待値は約 **140,551 Pa** と **4 m** です。

圧力係数は変更しません。増加量は **19,612.76 Pa** になるはずです。変更前後のファイルと観測結果を一緒に保存してください。

## 設定場所を確認する

| SDF のパス | 単位 | 用途 |
|---|---|---|
| `world/physics/max_step_size` | s | 最大積分時間刻み：`0.001` |
| `world/physics/real_time_factor` | — | シミュレーション時間と実時間の目標比：`1.0` |
| `world/gravity` | m/s² | 重力ベクトル |
| `world/scene`, `world/light` | RGBA / 方向 | 背景と照明 |
| `model/pose` | m, rad | 位置と姿勢 |
| `model/static` | 真偽値 | 観測点と海底を固定 |
| `model/plugin` | プラグインによる | [圧力設定](pressure.md) |

実際の実行速度は負荷で変わります。センサー定義とワールドのシステムでは設定範囲が異なります。[センサーを追加する](custom-sensors.md)では、このファイルに IMU と ROS ブリッジを組み込みます。

## ワールドを拡張する

- [ハイトマップ地形](heightmaps.md)：海底の置き換えと衝突の確認。
- [ロボットの追加](custom-robots.md)：機構、推進、ROS 設定。
- [海流](currents.md)：ワールドの流れとモデルの応答。
- [球面座標](coordinates.md)：地理座標の原点。
- [水中描画](underwater-rendering.md)：描画システムの設定。

配布するワールドは `models/posim_worlds/worlds` に、関連リソースは同じパッケージに保存します。追加後は再ビルドして環境を読み込み、共有時にはインストール済みリソースを参照する URI を使います。
