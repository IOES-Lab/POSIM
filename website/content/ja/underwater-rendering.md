# 水中シーンの効果

`posim_gz_rendering` は Ogre2 の PBR 表面に、水中のかすみ、RGB 吸収、深度による日光減衰、コースティクス、浮遊粒子を適用します。粒子はマリンスノーを簡易的に表し、初期状態では**無効**です。

Gazebo のシーン、RGB カメラ、RGBD のカラー画像で同じ効果を使います。数値深度と衝突形状は変わりません。別の深度ベース画像フィルターは[水中カメラ](camera.md)を参照してください。

システムは同じ場所の描画補助ライブラリと `share/posim/underwater` のシェーダーを自動で探します。`renderer_library` と `shader_directory` で上書きできます。海洋サンプルの起動ではカメラのパススルーフラグを自動設定します。独自の起動で両システムを使う場合は手動で設定してください。

## 効果と既定値

| 設定 | 効果 | 既定値 |
|---|---|---|
| 水中光学効果 | 光学効果全体の切り替え | 有効 |
| かすみ | 水中の光路長に応じた色の混合 | 有効 |
| RGB 吸収 | 波長に応じた色の減衰 | 有効 |
| 日光減衰 | 深くなるほど弱まる平行光 | 有効 |
| コースティクス | 水中表面を動く日光模様 | 有効 |
| 浮遊粒子／マリンスノー | 疎らに生成する明るい点 | 無効 |
| 海底テクスチャ | 海底に指定した PBR マップの細部 | 有効 |
| 海底グリッド | 間隔 10 m、1～500 m で調整可能 | 無効 |
| 等深線 | 間隔 5 m、1～50 m で調整可能 | 無効 |

光学効果を切っても、テクスチャ・グリッド・等深線の選択は保持されます。海底の重ね表示は `seabed` または `shallow` という visual を認識し、Gazebo の完全なスコープ名にも対応します。テクスチャは地形アセットに含めます。[ハイトマップ地形](heightmaps.md)を参照してください。

## モデルの範囲と比較

水中の光路長は **z = 0 m** の平均水面を基準に計算し、個々の波頂には追従しません。コースティクスと粒子は視覚的な近似で、校正された粒子濃度や光学センサーノイズは再現しません。

局所光源は直接照明を保ちます。空へのレイには水中減衰がかかりますが、unlit 材質や独自の海面シェーダーは自身の描画を保ちます。波面の裏側は海面材質の設定で扱います。

水面上と水中、RGB と RGBD カラー、各切り替えを比較します。姿勢と照明を固定し、深度がバイト単位で同一なこと、時間依存の効果がシミュレーションの一時停止に合わせて止まること、描画エラーが報告されることを確認します。[公開パッケージ](https://github.com/IOES-Lab/POSIM/tree/main/gazebo/posim_gz_rendering)には RGB/RGBD 確認用の例、シェーダー、ビルド情報があります。
