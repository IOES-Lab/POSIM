# センサーを追加・設定する

センサーには、モデル内の定義、更新を行うシステム、受信側へのデータ経路が必要です。1 つずつ追加し、計測値を確認してから次に進みます。

## 作業環境

Ubuntu ネイティブ、WSL、Docker の[準備済み Linux ターミナル](terminals.md)を使います。macOS では RDP デスクトップ内で作業します。編集とビルドもその環境で行い、`POSIM_WS` にはワークスペースのパスを使います。

## 組み込む場所を選ぶ

| 計測 | モデル内の配置 | ワールドのシステム / ROS 接続 |
|---|---|---|
| IMU | `link/sensor type="imu"` | IMU システム、`gz.msgs.IMU` から ROS `Imu` へのブリッジ |
| [水中カメラ](camera.md) | RGBD センサーと画像効果プラグイン | 描画エンジンを使う Sensors システム、カメラトピック |
| [DVL](dvl.md) | DVL センサーとビーム設定 | DVL システム、付属の音響メッセージブリッジ |
| [圧力](pressure.md) | `model` 直下のプラグイン | 圧力と深度を ROS に直接出力 |
| [海洋 GNSS](gnss.md) | ロボットモデルの受信機プラグイン | 設定した受信機の ROS 出力 |
| [USBL](usbl.md) | 送受信器とトランスポンダーのプラグイン | 対応する音響 ID と ROS インターフェース |
| [マルチビームソナー](sonar.md) | リンク下のカスタムセンサー | Sensors の描画、ワールドのマルチビームシステム、CUDA |

各リファレンスの SDF とパラメーター表を参照してください。配置には意味があります。ワールドのシステムはワールドに、モデル用プラグインは対象モデルに置きます。

## 更新周波数を変える

`update_rate` を `20` から `5` に変え、ワールドとブリッジを再起動します。時刻の間隔は、シミュレーション時間で約 **0.05 秒から 0.2 秒**に変わります。実時間での受信周波数は、シミュレーションの進行速度と転送にも依存します。

カメラでは解像度、視野角、近距離・遠距離の範囲をまとめて確認します。走査型センサーではビーム配置と測定範囲を確認します。センサーを動かす前に、基準リンクの座標系と向きを確かめてください。

## 組み込み結果を確認する

- モデル：正しい取り付け姿勢、設定、一意のトピック。
- ワールド：必要なシステムと、画像センサー用の描画エンジン。
- ROS：ブリッジ方向、メッセージ型、座標系、QoS。
- 計測：新しい時刻と、制御したシーン変更への応答。

海底の配置は[ハイトマップ地形](heightmaps.md)で確認します。ソナーの比較には[設定と性能](sonar-tuning.md)と[パラメーターリファレンス](sonar.md)を使ってください。
