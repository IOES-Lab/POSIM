# Ubuntu：ネイティブインストール

Ubuntu 26.04でPOSIMをビルドします。Ubuntuのターミナルを開き、各コードブロックを順番に実行してください。前の処理が完了してから次へ進みます。ビルド済みイメージを使う場合は[LinuxのDocker手順](install-ubuntu-docker.md)を参照してください。

## 1. ソースを取得する

{{CODE:install:0}}

取得先の名前は`posim`のままにしてください。後のリポジトリマニフェストがこの名前を使います。

## 2. ソフトウェアをインストールする

先に`src/posim/extras/ros-lyrical-gz-jetty-install.sh`を確認してください。パッケージリポジトリを設定し、`sudo`と`apt-get full-upgrade -y`を実行するため、専用のUbuntu環境を推奨します。

{{CODE:install:1}}

ROS 2 Lyrical、Gazebo Jetty、ArduSub、MAVROS、波のライブラリをインストールします。Wave Simは固定したリビジョンを取得してビルドする外部依存です。POSIMを再帰的にクローンする必要はありません。

## 3. ワークスペースの依存関係を準備する

{{CODE:install:2}}

`--skip-existing`は取得済みのPOSIMを保持します。依存関係のエラーが出た場合は、ビルド前に解決してください。

マニフェストは、ブリッジのライフサイクルとPOSIX起動処理を修正した`ros_gz`も固定リビジョンで取得します。既存の`src/ros_gz`は変更されません。取得元とリビジョンをマニフェストと比較するか、新しいワークスペースを用意してください。

## 4. ビルドして環境を読み込む

{{CODE:install:3}}

2つの`ros_gz`のパスが、このワークスペースの`install/`を指すことを確認します。`/opt/ros/lyrical`ならシステム側のパッケージが選択されています。新しいターミナルでは毎回、[ターミナルの準備](terminals.md)に従ってROSとワークスペースを読み込んでください。
