# Python で制御する

[最初のシミュレーション](quickstart.md)で REXROV を起動したままにします。別の[準備済みターミナル](terminals.md)で位置を読み、続いてスラスターに短い指令を送ります。

## 位置を購読する

次のプログラムを `observe.py` に保存し、ROS 環境を読み込んだターミナルで `python3 observe.py` を実行します。

約 1 秒ごとに位置が表示されます。Ctrl+C は観測プログラムだけを停止し、シミュレーションは続きます。

## 時間を制限した指令を送る

次を `pulse_thruster.py` に保存し、`python3 pulse_thruster.py` を実行します。購読先を待ってから、ホスト側の時間で約 2 秒間、**スラスター 1 に 5 N** を指令し、最後にゼロを送ります。生じる力とトルクはスラスターの取り付け軸で決まります。

{{CODE:python-control:1}}

シグナルの設定により、Ctrl+C を押しても ROS の配信機能が残っている間に終了処理を実行できます。プロセスを強制終了した場合はシミュレーターを止めるか、[スラスター制御](robot-control.md)に従って中立指令を送ってください。

## 応答を確認する

別の準備済みターミナルで、指令中の角速度を観測します。

{{CODE:python-control:2}}

角速度が指令に応答し、終了後にゼロへ戻る様子を確認します。オドメトリも見ると、アクチュエーターの応答と機体全体の移動を区別できます。Ctrl+C で表示を止めます。

## 制御器を作る

計測状態と制御則に基づいて、REXROV の 8 基のスラスターへ力を配分します。トピック名、取り付け軸、単位をそろえてください。実験の処理にはシミュレーション時刻を使い、終了時には操作したすべてのアクチュエーターに中立値を送ります。

BlueROV2 は [MAVROS／ArduSub](robot-control.md) を経由します。実験を比較するには[観測データを記録](visualization.md)してください。
