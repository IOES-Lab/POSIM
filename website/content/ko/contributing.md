# 기여하기

POSIM 코드와 문서 개선에 참여해 주세요. 다른 사람이 재현할 수 있는 작은 변경부터 시작하고, 모델·제어기 설정·문서의 내용을 함께 맞춰주세요.

## 브랜치에서 작업

```bash
git clone https://github.com/IOES-Lab/POSIM.git
cd POSIM
git switch -c my-change
```

시뮬레이션 변경에는 자신의 시스템에 맞는 [설치 환경](requirements.md)과 [준비한 터미널](terminals.md)을 사용합니다. 생성된 빌드·설치 디렉터리와 개인 인증 정보는 커밋에 넣지 않습니다.

## 변경한 동작 확인

관련된 최소 예제를 선택합니다. 리소스 경로, 모델 배치, 시뮬레이션 시간, 데이터 수신과 정상 종료를 확인합니다. 제어 변경이면 제어기 동작도 확인하세요. 결과에는 소스 커밋, 렌더러, 아키텍처와 명령을 함께 기록합니다.

센서·동역학 변경에는 적절한 수치 비교가 필요합니다. 스크린샷은 외관을 보여주며 물리 모델 정확도를 증명하지 않습니다. 기존 구현을 수정할 때는 원저자의 출처 표시를 유지하세요.

## 문서 갱신

문서는 영어·한국어·스페인어·프랑스어·독일어·이탈리아어·일본어·중국어를 지원합니다. 영어는 `/`, 나머지는 `/ko/`, `/es/`, `/fr/`, `/de/`, `/it/`, `/ja/`, `/zh/`를 사용합니다. `website/content/<언어 코드>`의 대응하는 Markdown 파일을 함께 갱신하고 명령, 단위, 준비 사항과 제한을 일치시키세요. 각 언어에서 실제로 쓰이는 로보틱스 용어와 자연스러운 문장을 사용합니다.

실행 예제와 미디어는 공통 `CODE`, `MEDIA` 자리표시자를 사용할 수 있습니다. 모든 언어에 전체 페이지가 필요하며, 누락된 본문을 영어로 대신 표시하지 않습니다. 페이지 순서는 공통이고 월드·물체 목록은 소스에서 생성합니다.

공개 기능을 변경할 때 소스와 함께 [기능 목록](features.md)과 사용 안내를 갱신합니다. 설치·활성화, 기본값, 단위, 입출력, 설정 범위, 관측 가능한 예제와 모델 한계를 설명하세요. 선택형 효과와 어댑터도 포함합니다. 패키지 README에만 적힌 기능은 사이트에서 찾기 어렵습니다. 새 페이지는 `website/scripts/pages.mjs`에 등록하고 `website/i18n/<언어 코드>.json`에 제목을 추가해 모든 언어의 메뉴와 검색에 포함합니다. 저장소의 언어별 README도 함께 갱신하세요.

현재 제품의 동작, 사용 방법과 제한 사항을 설명합니다. 개발 메모, 단계별 계획과 검증 보고서는 저장소 밖에 보관합니다. 변경 논의와 테스트 결과는 GitHub 이슈와 Pull request에 기록합니다.

Node.js 24와 pnpm 10.11.0을 준비한 뒤 `website`에서 실행합니다.

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm check
pnpm preview
```

`http://127.0.0.1:4174`를 열어 링크, 명령 복사, 검색, 언어 전환과 모바일 메뉴를 확인합니다. 호스팅과 유지보수 안내는 [website/README.md](https://github.com/IOES-Lab/POSIM/blob/main/website/README.md)에 있습니다.

## Pull request 작성

문제, 변경 후 동작과 검증 내용을 설명합니다. 시뮬레이션 변경에는 명령·로그를, 화면 변경에는 데스크톱·모바일 화면을 포함합니다. 실행한 검사와 아직 확인하지 못한 항목을 구분해 적어주세요.

재현 가능한 오류는 [GitHub 이슈](https://github.com/IOES-Lab/POSIM/issues), 변경 검토는 [Pull request](https://github.com/IOES-Lab/POSIM/pulls)를 사용하세요. 프로젝트는 [한국해양대학교 IOES-Lab](https://lab.wschoi.com)에서 관리합니다.
