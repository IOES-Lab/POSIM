# 투영 면적과 거리 감쇠 대조

[English](README.md)

이 기술 검증 기록은 표면 산란 계산의 거리 의존성을 확인합니다. 음선 한 셀의
투영 면적은 `r² Δθ Δφ`입니다. 수신 음압은 이 면적의 제곱근과 왕복 구면 확산
`1/r²`를 적용합니다. 입사각·반사율·각도 면적이 같으면 거리가 두 배일 때
적분 수신 전력은 1/4입니다. 실제 크기가 같은 표면 조각은 두 배 거리에서
차지하는 입체각도 1/4이므로 수신 전력은 1/16입니다. 이 비율은 흡수를 제외한
값이며, 별도 대조에서 흡수를 포함합니다. 면적과 확산 항은
[Choi 등(2021)의 식 2·8·14](https://kerednoslo.github.io/papers/Choi2021.pdf)에
근거합니다.

기존 CPU·CUDA·WGPU 식의 `sqrt(r Δθ Δφ)`를 `r sqrt(Δθ Δφ)`로 고쳤습니다.
음선 좌표계로 변환된 법선은 유지합니다. 세 번째 성분에 이미 입사각의
코사인이 들어 있으므로 센서 좌표계의 음선과 다시 내적하면 잘못됩니다.

| 5 m 기준 대조 | 예상 전력비 | 수정 전 | 수정 후 |
| --- | ---: | ---: | ---: |
| 같은 각도 면적의 셀, 10 m | 0.2500 | 0.1250 | 0.2500 |
| 같은 실제 면적의 표면, 10 m | 0.0625 | 0.03125 | 0.0625 |
| 같은 각도 면적, 흡수 0.05 Np/m, 10 m / 5 m | 0.091970 | 0.045985 | 0.091970 |

실제 WGPU C ABI를 호출해 빔 3개·음선 3개·거리 샘플 599개와 중앙의 단일
반사 셀을 계산했습니다. 단위 빔 혼합 행렬, 정규화한 직사각형 주파수 창,
최대 거리 15 m와 동일한 난수 프레임 두 개를 사용했습니다. 바이너리별 24회
호출의 복소 출력을 모두 보존했습니다. 전후 진폭은 예상한 `sqrt(r)` 비율로
달라지며 상대 L2 오차의 최댓값은 `2.93e-7`입니다. 면적·반사율·빈 반사·음선
좌표계 대조도 통과했습니다. 이는 기하 입력을 제공한 계산이며 새 현장
렌더링 기록은 아닙니다.

Python과 NumPy로 저장된 전체 출력을 독립적으로 확인합니다.

```sh
python verify_record.py
```

실제 백엔드를 호출하는 C++ 회귀 검사는 3·5·10·15 m의 각도 면적과 실제
면적, 흡수, 빈 반사를 확인합니다. 요청한 백엔드가 다른 구현으로 대체되면
실패합니다. 패키지 의존성과 WGPU vendor를 빌드한 환경에서 실행합니다.

```sh
cmake -S gazebo/posim_gz_multibeam_sonar/multibeam_sonar -B build/sonar \
  -DBUILD_TESTING=ON
cmake --build build/sonar --target scattering_range_test
ctest --test-dir build/sonar -R scattering_range_cpu --output-on-failure
build/sonar/scattering_range_test wgpu
```

CPU와 WGPU/Metal 실행 결과는 `result.json`에 보존합니다. CUDA도 같은 식을
수정했으나 이 Apple Silicon 장비에서는 실행하지 않았습니다. 599개 샘플
기록에는 별도 통합 브랜치의 #31–36 수정이 포함됩니다. 이 수정으로 해당
브랜치들을 #6에 병합하지 않습니다. 소유 브랜치는 64개 샘플의 C++ 대조로
별도 확인합니다.

이는 발표된 면적 항의 복원이며 새 연구 방법이나 실기 보정이 아닙니다.
원 논문 식 7과 14의 입사각 지수는 다릅니다. CPU 대체 구현과 GPU의 각도
법칙도 그대로 달라 이 기록으로 백엔드 간 산란의 동등성을 주장하지 않습니다.
물리적 빔 폭·출력 빔별 정규화·샘플링 수렴·시간에 따른 산란·새 현장 자료·
유용한 소나 SLAM 지도는 별도 검증으로 남습니다. 이 대조로 설치된 SDK나
실행 중인 항해를 교체하지 않습니다.
