# 소나 기하와 영상 대조 검사

[English](README.md)

센서는 설정한 수평 빔과 수직 광선으로 깊이 격자를 구성하며 대응하는 각도와
시야를 함께 유지합니다. 방사 거리는 구면 부채꼴 위의 표본입니다. 주변 점을
직교 좌표로 바꿔 표면 법선을 구하고 각 광선의 국소 좌표로 표현합니다.
전방 성분이 음향 입사각의 코사인을 제공합니다. 제한된 각도 이웃으로
해상도에 따른 거리 양자화 영향을 줄이고 경계에서는 가까운 면을 보존합니다.
이웃이 없는 고립된 반사는 법선을 만들지 않습니다.

설정한 음향 가시성 마스크를 깊이 카메라에 적용합니다. 미터 단위 부채꼴
미리보기 폭은 수평 시야를 반영하며 빈 반사에서 0으로 나누지 않습니다.
이 검사는 빠진 고도각을 추정하거나 SLAM 지도를 합격시키지 않습니다.

CPU 해석 검사는 64×32와 256×256의 정면·경사 평면 및 해저, 고립된 반사와
5 cm 단차를 다룹니다. 평면·단차의 입사각 코사인 오차는 0.001 미만이어야
합니다. 이는 기하 계산의 허용오차이며 센서 잡음이나 해양 지도 합격 기준이
아닙니다. ROS/Gazebo/OpenCV 환경에서 영문 페이지의 명령으로 실행합니다.

구면 법선 함수와 해석 검사는 Apache-2.0입니다. 기존 DAVE/WGPU 기여 이력과
고지를 유지합니다. 관련 수정은 각 PR에서 다룹니다. 초기 센서 자세는 #31,
촬영 시뮬레이션 시각 보존은 #32, 주파수 창 적용·Rust 의존성 고정 빌드는
#34에 속합니다. #33의 부분 행렬 타일 수정은 독립적으로 유지합니다.
최신 main 기반 별도 통합 브랜치에서 조합을 검증한 뒤 #6으로의 향후 병합을
논의합니다.
