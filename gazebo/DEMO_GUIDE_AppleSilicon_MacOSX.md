# Multibeam sonar on Apple Silicon

The public sonar build guide covers Metal for native macOS and CPU acoustic
processing in a Linux ARM64 container. Both require Gazebo rendering and a
matching ROS 2 / Gazebo environment.

- English: [Apple Silicon setup](../website/content/en/sonar-tuning.md#apple-silicon), [sensor and demo](../website/content/en/sonar.md)
- 한국어: [Apple Silicon 설정](../website/content/ko/sonar-tuning.md#apple-silicon), [센서와 예제](../website/content/ko/sonar.md)

Use the [Docker guide](../website/content/en/docker.md) or
[한국어 Docker 안내](../website/content/ko/docker.md) for a Linux ARM64 environment.
