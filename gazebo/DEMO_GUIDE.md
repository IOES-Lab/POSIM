# Multibeam sonar demo

Run the BlueView P900 demo with WGPU, CUDA or CPU processing. The public guides
cover build prerequisites, launch commands, backend selection, output topics
and troubleshooting.

- English: [run the demo](../website/content/en/sonar.md), [build and backend setup](../website/content/en/sonar-tuning.md)
- 한국어: [소나 예제 실행](../website/content/ko/sonar.md), [빌드와 계산 설정](../website/content/ko/sonar-tuning.md)

POSIM uses ROS 2 Lyrical and Gazebo Jetty. Start with the
[installation guide](../website/content/en/install.md) or
[한국어 설치 안내](../website/content/ko/install.md), then follow the sonar guides above.
